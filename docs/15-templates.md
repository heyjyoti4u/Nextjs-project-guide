# Templates and checklists

## Issue template

```text
## Problem
## Acceptance criteria
## Out of scope
## Owner and reviewer
## Dependencies
```

## Pull request template

```text
## What changed
## Why
## Files changed and why
## How to test
## Screenshots or API examples
## Migration and environment changes
## Risks and follow-ups
```

## Commit examples

`feat: add task creation form` · `fix: reject expired tokens` · `docs: explain local setup`

## Release note

Record the commit, user-visible changes, migration status, environment changes, known issues, and rollback plan.
